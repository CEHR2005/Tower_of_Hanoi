# Бенчмарки

Исходная серия перед оптимизацией: [таблица](../benchmarks/baseline-table.md),
[CSV](../benchmarks/baseline.csv), [окружение](../benchmarks/baseline.environment.txt).
Пять повторов N=16,20,24,26, один закреплённый CPU, GCC 12.2, Release -O3,
одинаковый получатель ходов и барьер компилятора. Время охватывает генерацию и
контрольную сумму, исключает печать, запуск процесса и чтение RSS.
Память измеряется по VmHWM из /proc/self/status после генерации; ru_maxrss
не используется, поскольку может включать пик родительского Python-процесса.

Исходный результат: iterative быстрее formula на N=24 и N=26. Следующий
эксперимент — замена ветвлений formula таблицей. Итоговый выбор и полная
методика будут зафиксированы после измерения этого изменения.
